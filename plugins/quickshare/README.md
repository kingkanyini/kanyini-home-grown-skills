# quickshare

> Save any skill or content as a shareable universal AI prompt with optional access control + expiration

**Tier:** T4
**Version:** 1.0.0
**Command:** `/quickshare`

## Usage

```
/quickshare [content-or-skill]
```

## Prerequisites

No prerequisites — standalone skill.

Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
