# Universal AI-ism Ban List

This list applies to ALL email drafts, regardless of user. The Voice Foreman scans every draft against these patterns before counsel review.

---

## Banned Phrases

| Don't Write | Write Instead |
|-------------|---------------|
| "Here's the thing..." | Just say the thing. |
| "Dive deep" / "deep dive" | "Break down," "get into," "look at" |
| "Unlock your potential" | Be specific about what they'll gain |
| "Let's be honest" / "Let me be real" | Just be honest. Don't announce it. |
| "Navigate" (metaphorical) | "Work through," "move through," "figure out" |
| "Leverage" (as verb) | "Use," "build on," "apply" |
| "At the end of the day" | Cut it. Make your point. |
| "It goes without saying" | Then don't say it. |
| "In today's world" / "In this day and age" | Cut it. Be specific about what changed. |
| "On a journey" | "Working through," "in the middle of," or just describe what's happening |
| "humming" (ambient scene-filler — "jungle humming," "the city humming," "the air humming") | Name the actual sound (birds, cicadas, a generator) or cut it. People don't narrate ambient "humming." |
| "In plain terms" / "simply put" / "to put it plainly" / "to be clear" (as a preamble) | Cut it. Say the thing plainly without announcing that you're about to. |
| "go flat" / "things that go flat" (casual filler idiom for losing energy/meaning) | Name what actually happens: "feels hollow," "loses its meaning," "stops mattering," "goes dead." (<your-name> directive 2026-07-06) |
| "know it cold" (cliché idiom for mastery) | "understand its depth," "master it," "remember your mastery." Ground it in real understanding, not the idiom. (<your-name> directive 2026-07-06) |

## Banned Structural Patterns

| Pattern | Instead |
|---------|---------|
| Starting with "So," or "Now," | Vary openings. Start with the point. |
| Ending with "Remember, [restatement]" | End with forward action or let it breathe. |
| "It's not just about X, it's about Y" | Make your point directly. |
| Overusing em dashes (--) between clauses | Max ONE per email. Use commas. |
| "You're not broken" | "You may feel broken, but..." — validate first, then reframe. |
| "Not X... But Y" contrast repeated | Max ONE per email. Rewrite the rest as direct statements. |
| "The one where..." trailing qualifier after a fragment pair ("Not X. The real Y. The one where...") | Cut "the one where" — make it a direct declarative statement. (Exception: a concrete, vivid vision payload is fine; only the abstract/wandering qualifier is banned.) |
| Starting consecutive paragraphs the same way | Vary your paragraph openers. |
| Triple-stacking rhetorical questions | Max ONE rhetorical question per section. |
| You-identity assignment ("Not you." / "That's you now." / "[X] is you." / "it's you") | Don't flip the reader's identity back at them. State the substance directly (e.g. "That file is you" → "That's your whole Voice DNA, one file"). |
| Analogy that ADDS complexity (stacked metaphors, an extended riff more elaborate than the point) | Analogies are GOOD when they simplify and connect (e.g. "the Scribe is your sous chef, you plate for the guest") — keep those. Only TIGHTEN or cut an analogy when it stacks, over-elaborates, or stops connecting. Never cut a clean simplifying analogy just for being one. |
| Same word twice as if it's poetic, but it isn't ("getting it 'right'... isn't getting any closer to right"; "the work works"; "you make it, but it isn't made") — the faux-profound echo where a repeated word stands in for an actual point | Replace the echo with real forward motion. Say what actually happens instead of spinning the same word. ("While you sit there getting it 'right', someone else already hit send and is getting responses.") The repeat has to earn its place with new information, not just rhyme with itself. |
