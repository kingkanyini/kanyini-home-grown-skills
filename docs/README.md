## Naming convention for docs (Mosh-rule)

Docs in this folder use **UPPERCASE** filenames when they document repo-level conventions (QUICKSTART, CONTRIBUTING, MARKETPLACE-CONTRACT, FEEDBACK, UPGRADING) and **kebab-case** for content docs (skills-by-tier, dependency-graph, prereq-setup, voice-and-counsel-build-guide). New docs follow the same split.
