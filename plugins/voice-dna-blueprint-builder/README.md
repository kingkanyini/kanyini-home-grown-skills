# voice-dna-blueprint-builder

> Interview-based Voice DNA Blueprint generator. Walks a subject through a counsel-locked question bank (5/10/15q), then synthesizes a transcript + blueprint MD.

**Tier:** T3
**Version:** 1.0.0
**Command:** `/voice-dna-blueprint-builder`

## Usage

```
/voice-dna-blueprint-builder
```

## Prerequisites

**Required skills** (install these first):
- `voice-dna-extractor`

**Recommended skills** (warning if missing, not blocking):
- `savepoint`


Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
