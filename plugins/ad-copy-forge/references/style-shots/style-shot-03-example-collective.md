- **First relief:** ~45% in ("body isn't the problem. It's trying to protect you")
- **Exit velocity:** Identity + urgency blend ("feel their success instead of just performing it" + "4 spots")

## WHY SELECTED AS STYLE SHOT / GOLD STANDARD

1. **Most complete skeleton:** Contains all 11 canonical sections including optional mirror (absent here but structure allows insertion).
2. **Near-perfect proportions:** Hook+Pain ~30% · Reframe+Intro ~22% · Bullets ~28% · Proof+Qualifier ~10% · CTA+P.S. ~10%. Hits every target zone.
3. **Chiasmus signature in headline:** *"Stop Performing. Start Being."* — archetype of the stop/start chiasmus move.
4. **Honor-first opening:** Best example of the honor-first rule (*"You've built the business..."* before *"your body is screaming"*).
5. **Triple-stacked CTA menu:** Demonstrates the high-ticket CTA pattern (3 parallel CTA lines instead of single button).
6. **P.S. as stakes amplifier:** Scarcity + qualifier ("isn't for everyone") + identity reframe — maximizes P.S. slot.
7. **Program-centric voice:** Zero "I" — program is the hero. Template for example-collective/coaching/healing ads without founder-voice.

## FIDELITY NOTES

When generating high-ticket somatic/coaching ads, use this as the reference for:
- Honor-first hook sequence (honor what they built → name paradox)
- Double triple-parallel (honor-ladder + symptom-ladder stacked)
- Verb-first internal-outcome bullets using `✓` (vs `✅` universal)
- Triple-stacked CTA menu (NOT single CTA button)
- Qualifier placement (AFTER bullets, BEFORE CTA)
- P.S. with scarcity + identity exclusion
- Zero "I" — program is always the subject

**Fidelity scoring target:** Generated high-ticket somatic ads should score ≥95% against this gold standard per `gold-standard-fidelity.md` rubric. This is the cleanest canonical template in the corpus — use as the primary template when in doubt.
