# overlay-director — Changelog

## 1.1.0

- New `/overlay-director import <playbook>` mode: learn from another creator's video. It reads the HyperFrames playbook from `/sixth-sense-xray` 1.1.0+ and runs every finding through the same approval gates as your own build lessons. Adds a fourth stop-gate (import approval).
- One evidence log for build and import lessons (`playbook/WATCHLIST.md`). Imported videos can promote a lesson for one video type, never globally; global promotion counts your own builds only.
- Nine moves now listed in the moves index so the auto-draft can pick them: two-tone-headline, callout-box, bar-fill, segmented-grid, slider-lane, date-timeline, pipeline-build, draw-board, pip-reframe.
- New `moves-library/_proposed/` folder for draft moves from imports. They are never auto-drafted; you promote one when a build needs it.
