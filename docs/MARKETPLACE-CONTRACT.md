# Not for redistribution

The formal marketplace contract has been retired in favor of one simple request.

**These skills are for your own use — please don't redistribute, repackage, re-host, or resell them.**

The repo is public so the bootcamp community can add it in one command, not so it can be re-shared. If someone wants in, send them straight to the marketplace and they can add it themselves:

```
/plugin marketplace add github:kingkanyini/kanyini-home-grown-skills
```

Provided as is, with no warranty. Support is best-effort through the community channels.

Thank you for honoring the work. 🙏
