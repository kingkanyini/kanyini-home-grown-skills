# exportskill

> Export Claude Code skills to Claude Web project knowledge format

**Tier:** T4
**Version:** 1.0.0
**Command:** `/exportskill`

## Usage

```
/exportskill [skill-name]
```

## Prerequisites

No prerequisites — standalone skill.

Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
