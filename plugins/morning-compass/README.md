# morning-compass

> 7-minute morning briefing for coaches — pulls from Google Calendar, Stripe, Calendly, ClickFunnels, Basecamp, Instagram, YouTube. Delivers single-page brief.

**Tier:** T2
**Version:** 1.0.0
**Command:** `/morning-compass`

## Usage

```
/morning-compass
```

## Prerequisites

**MCP servers:**
- `mcp__composio__*`
- `mcp__obsidian-brain__*`

**CLI tools:**
- `pwsh`
- `node`

**Environment variables:**
- `COMPOSIO_API_KEY`

**External services:**
- Composio
- Google Calendar
- Stripe
- Calendly
- ClickFunnels
- Basecamp
- Instagram
- YouTube


Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
