# counsel-dispatch

> Dispatch a counsel member from the vault. Loads their stat sheet, embodies their voice, and logs the dispatch for XP accumulation.

**Tier:** T1
**Version:** 1.0.0
**Command:** `/counsel-dispatch`

## Usage

```
/counsel-dispatch [slug] about [topic]
```

## Prerequisites

**MCP servers:**
- `mcp__obsidian-brain__*`


Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
