# Proposed moves

Draft moves learned from other creators' videos via `/overlay-director import` (fed by
`/sixth-sense-xray`). Every file here has `status: proposed`.

- **Not draftable.** The auto-draft, Variety Engine and standards generators only read top-level
  `moves-library/*.md`, so nothing in this folder reaches a build or the standards map.
- **Evidence grows.** Re-imports of the same move from another video add to its `evidence` field
  instead of creating a new file.
- **Promotion** happens only when a real build needs the move: `references/workflow.md`
  § Promoting a proposed move.
