# imaginator — Changelog

## 1.0.0 — Initial release

First version published in the <your-name> Home-Grown Skills Marketplace.

- Gemini image generation with named style presets (standard and premium tiers, up to 4K; Google requires billing for both), photo composites, scene stitching and HTML/SVG diagram mode.
- Video B-roll on two engines: Gemini Veo 3.1 (same Python script) or the OpenArt MCP (17 models with sound, voices and clips up to 30s).
- Optional Canva upload.
- The Gemini script ships with the plugin (`scripts/imaginator.py`). First-run setup saves your key in a private file from your own terminal, never in chat.
