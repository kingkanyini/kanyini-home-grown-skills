# web-dev-bot

> Build, clone, sketch, debug, and connect websites with Web Dev Counsel guidance

**Tier:** T4
**Version:** 1.0.0
**Command:** `/web-dev-bot`

## Usage

```
/web-dev-bot or /web-dev-bot "build a landing page for my retreat"
```

## Prerequisites

**Recommended skills** (warning if missing, not blocking):
- `counsel-dispatch`

**MCP servers:**
- `mcp__playwright__*`

**CLI tools:**
- `node`
- `python`

**External services:**
- Optional: mcp__obsidian-brain__* vault MCP powers the effects registry — without it the feature no-ops


Run `node preflight.mjs` from this skill's folder to verify all prereqs are met.
