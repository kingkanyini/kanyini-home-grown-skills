# sixth-sense-xray — Changelog

## 1.1.0

- New output choice at setup: CapCut playbook, Overlay Director hand-off, or both (recommended).
- New Agent 6 (HyperFrames Translator): maps what X-Ray finds to Overlay Director moves, draft move cards, standards proposals and portability flags, matched against your installed moves library. Feed the result to `/overlay-director import` (Overlay Director 1.1.0+).
- Finds Overlay Director in both local and marketplace installs.
- Projects started before this version keep working as CapCut-only.
